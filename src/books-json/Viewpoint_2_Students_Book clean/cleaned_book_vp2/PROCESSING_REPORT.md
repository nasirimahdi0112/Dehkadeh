## Verification methodology (Viewpoint 2) — multi-engine cross-check

**All 19 vocabulary-teaching pages with printed word lists were verified**
against the actual PDFs. The agent rendered each page from the scanned PDFs
and ran a **multi-engine independent OCR pass**, then required every target
item to be corroborated by **at least 2 distinct OCR engines**:

| Engine | Source |
|--------|--------|
| RapidOCR (onnxruntime) | agent re-render of the PDF page |
| Tesseract 5.5 — PSM 3 | agent re-render (independent engine) |
| Tesseract 5.5 — PSM 6 | agent re-render |
| Tesseract 5.5 — PSM 11 | agent re-render |
| RapidOCR (upstream export) | the provided page JSONs |

Result: **19 / 19 pages fully corroborated**; the large majority of items were
confirmed by 4–5 engines simultaneously. This matches (and slightly exceeds)
the 5-engine standard used for the Four Corners books.

**Schema note:** this book's JSONs use a different schema (pixel positions,
`sourcePdfPart`, no multi-engine audit). They were converted to the standard
schema by `work/normalize_input.py` before cleaning.

**Curation policy:** Viewpoint 2 teaches vocabulary through word families,
collocations, idioms, and word formation. Only items **printed on the page**
were curated (word-family charts, Word-builder boxes, collocation boxes,
idiom lists, suffix/prefix tips). Student-answer content (gap-fill answers
not printed on the page) was excluded — never guessed. Four "Focus on
vocabulary" pages (29, 72, 82, 92) contain only find-the-word exercises whose
answers are not printed, so they carry no curated vocabulary by design.

**Book structure:** 12 units × Lessons A–D + Focus on vocabulary + Vocabulary
notebook; 24 grammar topics; 12 "Lesson D" reading passages; "Grammar extra"
back-matter topics cleared.
