## Verification methodology (Viewpoint 1) — multi-engine cross-check

**All 16 vocabulary-teaching pages with printed word lists were verified**
against the actual PDFs. The agent rendered each page from the scanned PDFs
and ran a **multi-engine independent OCR pass**, then required every target
item to be corroborated by **at least 2 distinct OCR engines**:

| Engine | Source |
|--------|--------|
| RapidOCR (onnxruntime) | agent re-render of the PDF page |
| Tesseract 5.5 — PSM 3 | agent re-render (independent engine) |
| Tesseract 5.5 — PSM 6 | agent re-render |
| Tesseract 5.5 — PSM 11 | agent re-render |
| RapidOCR (upstream export) | the provided page JSONs |

Result: **16 / 16 pages fully corroborated**; the majority of items were
confirmed by 4–5 engines simultaneously.

**Schema note:** this book's JSONs use the same Viewpoint schema as Viewpoint 2
(pixel positions, `sourcePdfPart`, single-engine audit). They were converted
to the standard schema by `work/normalize_input.py` before cleaning.

**Curation policy:** only items **printed on the page** were curated
(word-family charts, Word-builder boxes, collocation boxes, idiom lists,
synonym/opposite tips). Student-answer content (blank fills) was excluded —
never guessed. This matters especially here: several pages print base words
and leave the derived forms (opposites with il-/in-/un-, adjective forms of
verbs) as blanks, and those answers were deliberately NOT curated.

**Book structure:** 12 units (Social networks → Ability) × Lessons A–D +
Focus on vocabulary + Vocabulary notebook; 23 grammar topics
(2 per unit except Unit 1); 12 "Lesson D" reading passages; "Grammar extra"
back-matter (144–167) and stray "Grammar"/"grammar chart" topics cleared via
`no_grammar` (41 pages).
