## Verification methodology (Four Corners 2)

**27 of 28 vocabulary-teaching pages were verified against the actual PDFs**
via independent OCR cross-check (the agent in this environment has no human
vision, so it rendered each page from the scanned PDFs and OCRed it fresh):

1. Rendered each teaching page from the original PDFs at ~3x scale.
2. Ran a **fresh RapidOCR pass on the raw pixels** (`work/verify_pages.py`),
   independent of the upstream pipeline that produced the input JSONs.
3. Cross-checked every target word against this pass **and** the existing
   4-engine audit (`work/finalize_verification.py`).
4. Promoted a page only when its **entire word list** was corroborated.
   Result: **27 / 28 pages fully corroborated**.

Resolutions recorded in the data (no invention):
- `bowl` (Unit 1 sports) — independent pass reads "bowt." (l→t misread);
  upstream RapidOCR audit reads "bowl." exactly.
- Match-the-word exercises (sports, indoor activities, healthy habits,
  appearance) print verbs and objects in separate columns — verified
  token-by-token via the finalizer's phrase fallback.

**One page not promoted:** pdf 37 (indoor activities) — the verb column is
stylized; every engine fails to read the verb for "a video" (printed noun
confirmed). The item "watch a video" is kept with `evidence: "ocr_crossref"`
and the page is flagged `needsReview` with the reason recorded, rather than
silently guessing.

Corroborated pages carry `verifiedAgainstPdf=true`,
`verificationMethod="independent_ocr_crosscheck"`, vocabulary
